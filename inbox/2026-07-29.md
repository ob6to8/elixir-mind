## The read

Today's protocol news and today's attack-research news are the same story from
opposite sides. MCP's 2026-07-28 specification ships a stateless core and
OAuth 2.1/OIDC-aligned authorization hardening — exactly the kind of surface
that matures once a protocol is load-bearing enough to need it. In the same
week, a Seoul National/UIUC/Largosoft team publishes Agent Data Injection: an
attack that forges the *metadata* an agent trusts (sender names, button IDs,
delimiter punctuation) rather than smuggling instructions, and clears
purpose-built injection defenses up to 50% of the time against Claude Code,
Codex, and Gemini CLI alike. It extends the brain's indirect-injection concept
(`em:7da513`) one layer down: bounding the action surface stops instruction
smuggling, but a fact an agent has no reason to doubt still isn't defended by
that mitigation. AISI's finding that open-weight models now trail frontier
*cyber* capability by only 4–7 months (down from 6–10) is the same
gap-compression dynamic driving the margin-collapse thesis (`em:07610c`), read
through a misuse lens instead of a pricing one — sovereignty and price relief
arrive bundled with a shorter lag before offensive tooling too.

The other throughline is capability-vs-reliability, continuing straight from
the 2026-07-12 digest. Opus 5 lands at Opus 4.8's price with gains across
agentic coding and long-horizon knowledge work, while SlopCodeBench supplies
the sharpest reliability data point yet: across 20 problems and 93 iterative
checkpoints, **no agent solved any problem end-to-end**, and code quality
erodes monotonically the longer an agent extends its own prior work — 2.2×
more verbose than maintained human code, cost growing 2.9× with no
correctness gain to show for it. That sits directly beside PARC (`em:f02167`)
and the scar-tissue drift finding in the agentic-loop reliability thread, and
hardens "test behavior, not lines" (`em:a5ea86`) for the specific case of an
agent iterating on code nobody is reading line-by-line.
