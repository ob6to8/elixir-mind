# scaled score

The practical consequence is that a scaled cut score cannot be read as a
percentage. A 720 on a 100–1,000 range is not "72% correct" — the mapping from
raw items answered to reported score is set per exam form by an equating
procedure, precisely so that candidates sitting different forms face the same
standard.
