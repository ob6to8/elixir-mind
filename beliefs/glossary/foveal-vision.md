# foveal vision

The consequence for display design is that vision is *serial* where hearing is
parallel: detail must be fetched by aiming the eye, so a dashboard with several
panels changing at once is read one panel at a time regardless of how well each
is drawn. Peripheral vision compensates only for coarse motion and luminance
change, which is why animated displays reach for pulses, glows, and pop-up
callouts — devices that compete for a gaze that can be in one place.

This is the asymmetry a
[sonification](/beliefs/glossary/sonification.md) exploits. Hearing needs no
aiming and tracks several concurrent sources
([auditory stream segregation](/beliefs/glossary/auditory-stream-segregation.md)),
so the channels a visual display must serialize can be delivered
simultaneously — and the eye keeps the jobs that need its acuity, namely exact
values and text.
