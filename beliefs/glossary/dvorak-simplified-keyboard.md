# Dvorak Simplified Keyboard

Selected in software (most operating systems ship it as a built-in layout
option), it changes which character each physical key produces without
altering the hardware — so its keycaps, printed for QWERTY, no longer match
what pressing them types. Two letters are unchanged from QWERTY (`a`, `m`);
every other letter moves. See
[the Dvorak–QWERTY positional mapping](/knowledge/human-computer-interaction/keyboard-layouts/dvorak-qwerty-positional-mapping.md)
for the full character/key correspondence in both directions.
