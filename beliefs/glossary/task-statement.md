# task statement

Blueprints typically pair each one with explicit *Knowledge of* and *Skills in*
bullets, making it the finest-grained published unit of what an exam measures —
finer than the weighted domain headings above it.

That granularity is what makes it useful as a **coverage denominator**: a study
programme can ask "which objectives have no practice question yet?" and get an
exact answer, where a domain heading only supports a vague sense of proportion.
