# post-training

Pre-training installs knowledge and linguistic competence; this later phase
installs *disposition* — how the model responds, refuses, and presents itself.
Techniques include supervised [fine-tuning](/beliefs/glossary/fine-tuning.md) on
instruction data and reinforcement learning against a
[reward model](/beliefs/glossary/reward-model.md). It is one of the three
mechanisms (alongside RL enforcement and
[context engineering](/beliefs/glossary/context-engineering.md)) by which an
agent's apparent character is deliberately constructed rather than emergent.
