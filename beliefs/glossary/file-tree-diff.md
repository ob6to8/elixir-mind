# file-tree diff

Each annotated line carries a one-clause purpose (`# NEW - wraps API contract calls`), so the artifact doubles as a table of responsibilities. Because this bundle's directory tree *is* its taxonomy, the same notation extends beyond code: a plan proposing knowledge-shape changes can diff the bundle tree itself. Artifact 2 of the [structured-plan-bodies policy](/meta/policy/structured-plan-bodies.md)'s kit, alongside the [call-stack tree](/beliefs/glossary/call-stack-tree.md).
