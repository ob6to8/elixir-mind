# definition of done

Standard Agile/Scrum vocabulary for the completion checklist attached to a
unit of work, most often an [epic](/beliefs/glossary/epic.md). James C.
Davis's *Model-Based Agentic Software Engineering* (MAGE) uses it as the
concrete instrument for closing the [semantic gap](/beliefs/glossary/semantic-gap.md):
a condition like "the model matches the code" belongs in the definition of
done, checked once the agent returns from the whole task, rather than
enforced (and failed) at every intermediate commit where it may legitimately
not yet hold.
