# criterion-referenced assessment

The contrast is *norm-referenced* scoring, where a candidate's result depends on
the distribution of other candidates' results — a curve. Criterion-referencing
removes that dependency, which is what makes a professional credential portable:
holding it asserts a capability level, not a rank within a cohort.

The fixed standard is usually set by a formal **standard-setting study**, in
which trained subject-matter experts judge the performance expected of a
*minimally qualified candidate*. That judgment, not a target pass rate,
determines the cut score.
