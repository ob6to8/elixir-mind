# motor program

A skill practiced enough to become one motor program stops requiring
per-element retrieval, which is why a fluent typist doesn't consciously
recall each letter of a word — and why an isolated, out-of-sequence key
press (the kind a keybinding like vim's demands) can still stall a typist
whose prose speed depends on programs built around whole words rather than
single characters.
