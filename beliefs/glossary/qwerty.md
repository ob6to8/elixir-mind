# QWERTY

Because the keycap engraving is physical and the active layout is a software
setting, a machine running a non-QWERTY layout (such as
[the Dvorak Simplified Keyboard](/beliefs/glossary/dvorak-simplified-keyboard.md))
typically still shows QWERTY labels — the mismatch a layout-aware keybinding
reference exists to bridge.
