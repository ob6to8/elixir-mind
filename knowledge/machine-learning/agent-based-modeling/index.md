# Agent-based modeling

Emergent coordination from local or pairwise agent rules — flocking,
swarming, and related complex-systems simulation. Distinct from
[evolutionary-computation](/knowledge/machine-learning/evolutionary-computation/index.md),
which covers population/distribution-based search and optimization.
