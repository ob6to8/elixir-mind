# Rust audio DSP ecosystem: rust.audio and the awesome-audio-dsp list

## rust.audio — the community hub

rust.audio describes itself as a collection of resources dedicated to the
development of audio applications in the Rust programming language,
spanning DSP, synthesis, and plugin development. It is deliberately thin as
a content host and functions mainly as a gateway, split into two sections:
Community (Discord server, GitHub organization, community guidelines, an
AI-usage policy) and Resources (a pointer to awesome-audio-dsp plus
additional DSP learning material).

## awesome-audio-dsp — the curated list

Maintained by BillyDM, described as a curated list of audio DSP and plugin
development resources aimed at developers "from complete beginners to
experienced practitioners." Despite being reached through a Rust-community
hub, the list itself is language-agnostic — entries span C++, Rust, Python,
and D. Nineteen category headings structure it: Code Libraries, DSP
Cookbooks, DSP Playgrounds, Electronics & Embedded, Forums, Free Online
Textbooks & Courses, Graphic Design and UX, Machine Learning, Mathematics,
More Lists, Open Source Plugins & Software, Paid Textbooks, Plugin APIs,
Plugin Development Frameworks, Programming Languages, Software Optimization,
Sound Design & Music Production, System Tools, Technical Reading.

The breadth (electronics/embedded, ML, mathematics, and UX/graphic-design
categories alongside the expected library/framework/textbook ones) makes
this the widest-scope curated entry point this bundle currently holds for
audio DSP development generally, not narrowly Rust.
