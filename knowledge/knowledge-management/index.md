# knowledge-management

methods for capturing and organizing knowledge — including the format this brain
itself is built on.

- [Open Knowledge Format (OKF)](/knowledge/knowledge-management/open-knowledge-format.md) — the open markdown-bundle format this second brain is stored in (OKF v0.1).
