# Biases

Human cognitive biases — systematic, directional deviations in human
judgment, one `type: concept` document per bias. Entries carry **strictly
human-behavioral evidence**; where an agentic parallel exists it lives in the
agent-side register (per the
[two-sided bias-taxonomy plan](/meta/plans/two-sided-bias-taxonomy-and-compendium.md))
and the pair cross-links as *analogical, never identical* — same
phenomenology, different machinery.

First entries arrive with that plan's implementation:
[einstellung-effect](/beliefs/glossary/einstellung-effect.md) (`em:837963`)
refiles here from the glossary, which then keeps a pointer entry.
