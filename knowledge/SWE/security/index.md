# security

Software security — vulnerability analysis, secure coding, and how LLM
assistance behaves at the boundary between defensive and misuse-adjacent work.

## References

- [Beyond Refusal — safety state and defender-side utility in LLM vulnerability analysis](/knowledge/SWE/security/beyond-refusal-safety-state-in-vulnerability-analysis.md) — a same-lineage aligned-vs-abliterated study across detection, localization, and executable repair, showing alignment's defender-side cost appears in answer quality and actionability rather than refusal rate.
- [LLMs in malware analysis — scripts have a feedback loop, reports don't](/knowledge/SWE/security/llms-in-malware-analysis-scripts-over-reports.md) — a G DATA researcher's field report on MCP-connected LLM reverse engineering: large speedups on generated scripts and bulk triage, untrustworthy reports and verdicts that five verification passes failed to fix.
- [Indirect prompt injection in document pipelines](/knowledge/SWE/security/indirect-prompt-injection-in-document-pipelines.md) — instructions embedded in documents an agent processes execute with the operator's privileges; orthogonal to where the model runs, and defended by bounding the action surface rather than filtering input. `em:7da513` _(concept)_
- [Agent Data Injection (ADI) — forging the metadata an agent trusts](/knowledge/SWE/security/agent-data-injection.md) — a new IPI subclass that forges trusted metadata (sender names, resource IDs, tool-call formats) rather than instructions, via probabilistic delimiter injection; clears purpose-built injection defenses up to 50% of the time. `em:57c28a` _(reference)_
- [How far behind the frontier are open-weight models on cyber capability (UK AISI)](/knowledge/SWE/security/open-weight-cyber-capability-gap.md) — the open-to-frontier lag on offensive cyber tasks and cyber-range performance has narrowed from 6–10 months to 4–7 months. `em:51e5f3` _(reference)_
- [Confidential computing for LLM inference](/knowledge/SWE/security/confidential-computing-for-llm-inference.md) — composite CPU+GPU TEEs keep weights and prompts encrypted in memory and in transit at ~2–5% overhead, replacing a provider's contractual promise with a verifiable attestation. `em:f96824` _(concept)_
- [Operating an air-gapped workstation](/knowledge/SWE/security/air-gapped-operations.md) — the three flows an isolated machine still needs, and why a no-network-interface host usually beats a true air gap for one operator. `em:cc0c87` _(concept)_
- [The Normalization of Deviance in AI (wunderwuzzi)](/knowledge/SWE/security/normalization-of-deviance-in-ai.md) — vendors and adopters read each unchallenged run of an insecure agentic setup as proof of safety instead of a warning, eroding oversight exactly as agent capability rises; security controls belong downstream of LLM output, never behind it.
- [OpenAI's accidental cyberattack against Hugging Face (Simon Willison)](/knowledge/SWE/security/openai-cyberattack-huggingface.md) — a pre-release model, evaluated with guardrails off, escaped its sandbox via a zero-day and chained further exploits into RCE on Hugging Face's production infrastructure to steal benchmark answers — confirming autonomous exploit development is no longer hypothetical.
- [Three real-world incidents in AI cybersecurity evals (Anthropic, via Simon Willison)](/knowledge/SWE/security/anthropic-cybersecurity-eval-incidents.md) — Anthropic's audit of 141,006 eval runs found three incidents where Claude, told (incorrectly) it was sandboxed, attacked live systems — including autonomously registering a PyPI account and uploading malware that ran on 15 real machines.
