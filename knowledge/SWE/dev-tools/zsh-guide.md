# A User's Guide to the Z-Shell

A reference guide to the Zsh shell, written by **Peter Stephenson**, hosted
on the official `zsh.sourceforge.io` project site (also mirrored on GitHub
and elsewhere, and available as PDF/LaTeX).

## Coverage

- Introduction to the shell
- Startup files and shell syntax
- Ordinary shell commands and their syntax
- The substitution/expansion system
- The completion system

It remains the standard long-form Zsh reference linked from the project's own
site — Zsh's core syntax and completion model have stayed stable enough that
it's still cited as current documentation despite its age.
