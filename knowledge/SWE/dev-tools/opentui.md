# OpenTUI

OpenTUI is a library for building terminal user interfaces, implemented in
Zig with TypeScript support — usable directly or through React and Solid
framework bindings. MIT licensed.

## Features

- **Flexbox layout system** for arranging boxes and text.
- **Interactive components**: selects, inputs, and scroll boxes with both
  keyboard and mouse control.
- **Multimedia in the terminal**: sound playback, image display, and 3D
  graphics rendering.
- Used in production by [OpenCode](https://opencode.ai), reportedly serving
  millions of users.
