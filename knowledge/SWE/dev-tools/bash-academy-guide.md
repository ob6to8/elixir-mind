# The Bash Guide

A Bash scripting guide by **Maarten Billemont (lhunath)**, published under
CC BY-SA 4.0 with its source on GitHub — community-editable, and the direct
Bash counterpart to
[A User's Guide to the Z-Shell](/knowledge/SWE/dev-tools/zsh-guide.md)
already filed here for Zsh.

## Coverage

Eleven chapters spanning: installation and basics, command syntax and
arguments, variables and parameter expansion, conditionals and testing,
loops and functions, background processes and job control, terminal
customization/colors, advanced scripting techniques, best practices and
pitfalls, and external tools that extend Bash. Concept sections are paired
with practical exercises.

## Stated purpose

The guide positions itself explicitly against "naive advice, poor practices,
and outright misinformation" that circulates in shell-scripting education,
aiming to teach both correct usage and how to write "safe and robust bash
scripts" — under continuous, active revision rather than treated as a
finished, static reference.
