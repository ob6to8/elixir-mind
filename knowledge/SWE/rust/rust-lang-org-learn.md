# rust-lang.org — Learn Rust

The Rust project's own index of learning material, organized by entry point
rather than by topic.

## Getting started

- **[The Rust Programming Language](https://doc.rust-lang.org/book/)** ("the
  book") — the canonical prose introduction, covering the language through a
  sequence of built projects.
- **Rust by Example** — terse, code-first: minimal prose, runnable snippets,
  and exercises, for readers who learn faster from examples than narrative.
- **[Rustlings](/knowledge/SWE/rust/rustlings.md)** — a CLI-driven exercise
  course covering toolchain setup and core syntax.

## Reference layer

Links out to the standard library API docs, the Edition Guide, the Cargo
Book, and the compiler-side references (`rustc`, `rustdoc`, the error index),
plus domain guides for command-line applications and embedded targets.

## Advanced material

Separate sections cover `unsafe` Rust and unstable/nightly-only features, kept
apart from the beginner path.

This page is the navigational root the rest of this directory's Rust learning
resources — Rustlings, the Brown University annotated book, Command-Line
Rust — sit underneath or alongside.
