# Claude Agent SDK

Anthropic's SDK for building custom agents on the same harness that powers the
[Claude Code](/knowledge/SWE/agentic/anthropic/claude-code/index.md) agent —
programmatic access to the agent loop, tools, and MCP integration.

## Notes

- [Claude Agent SDK — Claude Code as a library](/knowledge/SWE/agentic/anthropic/claude-code-sdk/claude-agent-sdk-overview.md) — the same agent loop, built-in tools, and context management that power Claude Code, exposed as a Python and TypeScript library; covers hooks, subagents, MCP wiring, the three-way permission semantics, sessions, and how it differs from the Client SDK and Managed Agents.
