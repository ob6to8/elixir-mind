# Settle model-attribution

[model-attribution](/meta/policy/model-attribution.md) (ratified 2026-07-31)
requires agent-authored governance and statement docs to name their producing
model in `provenance`, display form. The
[epistemology review](/meta/analysis/epistemology-and-governance-review.md)
§4: zero of the 41 policies carry `provenance` at all (verified 2026-08-01);
the doctrines split across five forms the policy forbids coexisting; "a
ratified rule with zero instances teaches agents that ratified rules are
optional." Do not leave standing. (Post-matter-system docs — matter docs,
new policies — do now name the model, so the gap is the pre-existing corpus
plus enforcement.)

**The decision space, updated from the originating thread:**

- **(a) Enforce + backfill now.** Dry-run 2026-08-01: creating-commit
  `Co-Authored-By` trailers (via `git log --follow`, merge commits excluded)
  yield a display-form model for ~46 of 50 policy+doctrine files (≈31 Claude
  Opus 4.8 / 12 Claude Fable 5 / 3 Claude Opus 5); the rest get the policy's
  own `model undisclosed`. Backfill-from-recorded-evidence only, the
  session-URL precedent. Plus: normalize the seven agent-authored doctrine
  forms from their commits' trailers; file the warn-only presence+form
  verifier rule as its own follow-on matter.
- **(b) Fold into the span-level-attribution migration** — the accepted
  [span-level-attribution plan](/meta/plans/span-level-attribution.md)
  already ratifies "the model's single home in `attribution.agent`,
  recovered from filing-commit trailers at migration": the same trailer
  derivation, into a structured field, superseding free-text `provenance`
  naming. Under (b) this matter delivers only the ruling record: the policy
  stands, conformance arrives with that migration, and a free-text backfill
  now would be migrated away.
- **(c) Retract.** The original counter-case (trailer already carries the
  model; a third home is the shadow-copy pattern) — weakened by the policy's
  own answer (a trailer attributes a commit, not a document; documents
  travel), and by (b) offering the same economy without un-ratifying.

**Recommendation carried from the originating thread: (b)**, with the
doctrine-form normalization (the five-forms defect) executed now under
either (a) or (b) — it is evidence-based, small, and the span-level
migration consumes cleaner input.
